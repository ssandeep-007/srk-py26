Reverse each word of the given string
---------------------------------------------

Write a program to implement a logic to reverse each word of the given string.  
The string is composed of words separated by a space.  

Example: 
Input: Apple Fruit 
Output: elppA tiurF 

Input: Hello World 
Output: olleH dlroW 

-----------------------------
#CODE
def reverseWords(s):
    words=s.split()
    for i in range(len(words)):
        words[i]=words[i][::-1]
    return " ".join(words)
s=input("enter string with spaces: ")
res=reverseWords(s)
print(res)
